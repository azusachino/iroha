# Iroha design archive

This directory records visual and interaction experiments that informed the current frontend. The brand premise is `iroha`: _iro_ as sound / tone, joined with _hana_ as flower and gorgeous bloom. The
archived designs remain in the repository for reference:

- `/design` — the design lab with seven Today treatments.
- `showcase-v1.md` — the archived day-constellation / observatory concept.

These are references, not alternate production entry points. Production UX belongs to the domain routes and should reuse the useful parts of an archived concept without inheriting its assumptions.

## Archive rule

When a visual direction is replaced, keep a short decision record here with:

1. the user job it was trying to serve;
2. the parts worth carrying forward;
3. the reason it was not adopted wholesale; and
4. the production routes that inherit the decision.

The design lab remains a running, data-backed reference. The showcase was intentionally retired after its strongest visual language moved into Today.
