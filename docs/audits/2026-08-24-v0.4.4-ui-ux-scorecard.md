## Scale

Scores use 1 (weak) through 5 (excellent). They are calibrated observations, not executable release gates.

- **Philosophy:** the route expresses Iroha's quiet, evidence-preserving purpose.
- **Hierarchy:** the question, answer, and next action read in the intended order.
- **Execution:** layout and interaction hold together at both viewports.
- **Specificity:** copy and presentation belong to this personal-data cockpit.
- **Restraint:** the route avoids decoration or interaction without informational value.
- **Variety:** registered languages remain meaningfully distinct where the route owns themed composition.

## Findings and follow-ups

1. **Admin variety scored 2.** Carry this into the planned broader-hierarchy epic: give app-only Admin a specific operational question and compact utility-header contract without inventing a seventh
   design language.
2. **Today empty-state variety scored 3.** The shared empty state is appropriately restrained, but future typed specimens should decide whether empty states need language-owned phrasing or marks. This
   is not a release defect.
3. **Metrics variety scored 3.** Truthful selection and empty states matter more than decorative divergence. The typed specimen catalog should document which metric surfaces are intentionally shared
   and which are theme-owned.
4. **The review found a current-date URL startup error.** `/?date=<today>` attempted SvelteKit state replacement before router initialization. Commit `88530de` defers URL synchronization and adds the
   route to the structural inventory; a rebuilt production bundle canonicalized the URL with no page errors.
5. **Motion remains deliberately unscored.** Normal motion was used only to record the review context. Semantic motion and reduced-motion parity remain the separate follow-up epic named in the plan.
