## Governing Guardrails & Release Policies

> **Release NO-GO Remains Active:**
> No version bumps, release tags, changelog additions, Kubernetes cluster deployments, image imports, database migrations, or live-data operations are authorized until all gates through H8 have passed and received final signoff. PR #126 must remain in **Draft**.

1. **Immutable Historical Evidence:** Never overwrite archived evidence bundles or historical runs in `.tmp/iroha-acceptance-resume/`. All new matrix runs, probes, and reports must be stored in newly timestamped, isolated directories (e.g., `.tmp/runs/matrix-<timestamp>/`).
2. **Deterministic Playwright Execution:** Always execute tests using the source-installed Playwright package directly via Node (`node vendor/iroha/apps/iroha-web/node_modules/@playwright/test/cli.js`). Never rely on dynamic `npx` or `bunx` package resolution.
3. **No Silent Retries or Assertion Weakening:** Tests must pass strictly with `retries: 0`. Any failure must be investigated and resolved at root rather than bypassed with increased timeouts or suppressed assertions.

### Phase 2: H4 Acceptance Gap Closure

#### Task 4: Resolve Static-Production Overview ECharts Discovery

- **Asobi Task:** `iroha:v0.6-acceptance:task-4`
- **Owner:** `engineer team`
- **Root Cause:** Helper `pilot-charts.ts` searches `performance.getEntriesByType("resource")` for regex `/\/echarts_core\.js(?:\?|$)/`. In static production (`apps/iroha-web/build`), chunks are hashed (`_app/immutable/chunks/`), causing module discovery to return 0 marks.
- **Actions:**
  1. Update ECharts test inspection in `pilot-charts.ts` / `rendered-contrast.ts` to locate initialized chart instances from mounted DOM elements (`[role="img"] canvas`) or export hooks rather than hardcoded dev-server script filenames.
  2. Verify chart rendering on static production builds at `/overview` (Year progress, monthly bars, small multiples).
  3. Validate that `expect.poll(...).toBeGreaterThan(0)` succeeds against static build on port 5193.
- **Exit Criteria:** Zero-mark static failure resolved; chart marks reliably measured on production build.

#### Task 5: Remediate 1,345 Unmeasured Text Contrast Samples

- **Asobi Task:** `iroha:v0.6-acceptance:task-5`
- **Owner:** `engineer team`
- **Root Cause:** DOM walker in `pilot-measurements.ts` flags text nodes as `unmeasuredText` whenever ancestor styles contain CSS gradients (`.stat-tile`, `--tile-surface`) or `opacity !== 1`.
- **Actions:**
  1. Implement gradient-aware background color evaluation or pixel luminance sampling (using Playwright CDP viewport screenshots or canvas context reading) in `pilot-measurements.ts`.
  2. Audit all 1,345 text occurrences across `/overview`, `/`, `/night`, `/library`, and `/metrics`.
  3. Verify that all body and heading text meets WCAG AA ($4.5:1$ for normal text, $3:1$ for large text) across light and dark themes.
- **Exit Criteria:** `unmeasuredText` reduced to 0; all 1,345 samples evaluated with zero contrast violations.

#### Task 6: Complete Remaining Route Coverage & Admin Browser Observers

- **Asobi Task:** `iroha:v0.6-acceptance:task-6`
- **Owner:** `engineer team`
- **Actions:**
  1. Verify Night route end-column, category navigation reach, and table focus traversal.
  2. Inspect and verify authentication, passkeys, and session state observers.
  3. Verify the 19 Admin browser-status indicators in `apps/iroha-web/e2e/admin-intake-states.spec.ts` under live mock conditions.
- **Exit Criteria:** All H4 routes, views, and observers have passing automated e2e coverage.
